# 對話順序（實際開發時間序）

本資料夾各份「與 Claude 的對話整理版」，依**實際發生的時間先後**排列如下：

1. **問題釐清** — 界定 10-K item-level segmentation 的問題本質、難點與範疇（只做分段、不做合規判定）。
2. **策略定案與 Stage 1–3 設計** — 定案核心策略：錨點＝item 編號＋順序、ruler、確定性切割、結構不變量閘門。
3. **Stage 0 設計** — 回頭補齊地基：財年末抽取 → era ruleset → picker 的三柱架構。
4. **抽樣驗證 part 1** — Level-2 廣度抽樣驗證（第一批真實 filing）。
5. **抽樣驗證 part 2** — Level-2 廣度抽樣驗證（後續批次真實 filing）。
6. **前端與 URL 設計** — Streamlit 前端與可公開存取的部署 URL。

> 註：以上為**開發時序**，與最終 pipeline 的 Stage 0→3 編號並不相同——Stage 0 的地基是在 Stage 1–3 之後才回頭補齊的，這正反映真實的開發軌跡。各項對應本資料夾中名稱相符的 `.md` 檔。
