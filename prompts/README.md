# prompts/

本資料夾保存本專案開發過程中，與 Claude（策略對話層）的主要 prompt 紀錄整理版。

## 內容
- 每份 `.md` 是一輪（或一個主題）與 Claude 對話的整理版，涵蓋問題分析、設計決策的推導，以及據此產生、複製給 Claude Code（VS Code 擴充）執行的自足指令。
- 因此，給 Claude Code 的執行指令本身也包含在這些對話紀錄內——它們是在與 Claude 的對話中撰寫、再複製到 Claude Code 執行的。
- 閱讀順序見 `00_對話順序.md`。

## 關於錨定（誠實說明）
- 對話並非帶行號的逐字稿，無法標示「第幾行」（硬編等於捏造）。
- 客觀錨點以 commit hash + 階段 為準；各階段對應的實際 commit 請對照 repo 的 `git log`。

## 與其他文件的關係
- README 的「AI 協助環節」:協作分工摘要。
- 本資料夾:實際的 prompt 紀錄。
- 分析報告（隨繳交附上）:設計決策與驗證的完整論述。
